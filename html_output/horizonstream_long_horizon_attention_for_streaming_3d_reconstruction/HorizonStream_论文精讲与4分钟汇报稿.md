# HorizonStream 论文精讲与 4 分钟汇报稿

论文：*HorizonStream: Long-Horizon Attention for Streaming 3D Reconstruction*

一句话主线：

> HorizonStream 的关键不是“记住一切”，而是让不同几何证据以不同速度遗忘：局部注意力筛掉不可靠对应，几何线性注意力在固定状态中保存多种时间尺度，MRT 再从持久几何中读出统一尺度、位姿与深度。

## 1. 论文究竟要解决什么

任务不是离线地把一小段视频一次性重建完，而是持续接收一条可能很长的 RGB 视频流，并在每个时刻输出：

1. 当前相机位姿；
2. 当前帧的稠密深度与置信度；
3. 由位姿和深度形成的三维点云或连续重建结果。

系统还必须同时满足三个约束：

- **因果**：第 \(t\) 帧只能看当前与过去，不能读取未来帧。
- **在线**：新帧到达后应持续更新结果，而不是等整段视频结束。
- **有界状态**：持久记忆大小不能随着序列长度不断增长。

所以开场一定要区分：

> “还能处理第 10000 帧”只说明程序还能输出，不自动说明第 10000 帧的位姿、深度和尺度仍然稳定。

长序列中很小的局部匹配误差、旋转误差或尺度偏差会不断累积，最终表现为轨迹抖动、漂移、结构重复或地图撕裂。

## 2. 现有记忆机制为什么容易失败

论文用 Figure 1 把历史证据对当前时刻的影响写成影响核 \(K(t,i)\)，其中 \(i\) 是历史帧，\(t\) 是当前帧。问题不只是“记多少”，而是影响核的形状不合理。

### 2.1 滑动窗口：硬截断

只保留最近 \(W\) 帧时，窗口内证据权重存在，越过边界后突然变成零。

- 优点：计算和存储明确可控。
- 问题：仍有价值的长期结构、方向或尺度基准会在窗口边界被一次性删除。
- 直觉：不是慢慢忘记一张旧照片，而是到期瞬间撕掉整页。

### 2.2 周期刷新或压缩：不连续遗忘

有些方法周期性压缩、摘要或刷新记忆。

- 优点：比无限缓存更可扩展。
- 问题：刷新前后的历史表示可能不连续，容易出现阶段性跳变；统一摘要也可能把短期精细对应和长期结构混在一起。

### 2.3 因果注意力：attention sink

长因果注意力中，少数早期 Token 可能吸收过多注意力。

- 后果：早期证据长期占据影响力，即使已经过时，当前帧仍被它牵制。
- 注意：这是论文讨论的一种风险，不应说成所有因果 Transformer 必然失败。

### 2.4 无门控递归：陈旧状态重尾

若递归状态只累加而没有受控遗忘：

- 错误证据可能不断写入；
- 状态可能饱和；
- 初始化或很早的噪声会形成不衰减的长尾。

四类现象的共同根因是：**局部纹理、运动结构、全局尺度本来拥有不同有效寿命，却被迫共用同一套保留规则。**

## 3. 核心思想：把“信不信”和“记多久”拆开

论文首先把历史证据的影响分解为：

\[
K(t,i)=K_{\text{spatial}}(t,i)\,K_{\text{time}}(t,i)
\]

- \(K_{\text{spatial}}\)：这条局部几何对应在内容和空间上是否可靠。
- \(K_{\text{time}}\)：这条证据经过若干帧后还应该保留多少。

这一步很重要，因为“错误对应”与“正确但已经过时的对应”不是同一个问题：

- 前者应在写入长期状态前被局部门控压低；
- 后者应通过连续时间衰减逐渐退出，而不是突然删除。

一句通俗例子：

> 同一台相机拍摄城市长镜头。清晰度印章决定一条线索现在可信不可信，显影速度决定它以后淡得多快。两者不能共用一个旋钮。

## 4. Figure 3 Pipeline 应该怎样讲

讲 Figure 3 时按真实数据流走，不要把三个创新点讲成互不相关的模块：

1. **输入与 Token 化**：RGB 流被编码为图像 patch Token，并加入位姿 Token 与 Metric Readout Token。
2. **局部因果窗口**：只在最近窗口内进行细粒度对应。
3. **Geometric Local Attention**：判断局部匹配是否可靠，加入时空相对位置。
4. **Geometric Linear Attention**：把跨窗口几何写入固定大小的递归状态，并按通道使用不同保留率。
5. **重复堆叠**：局部精确匹配和长期状态传播在网络中协同出现。
6. **MRT 与位姿融合**：从持久状态读取统一正尺度，由多个局部位姿 Token 共同预测相对位姿。
7. **预测头**：输出位姿、深度、置信度，并形成三维重建。
8. **可选 Loop Closure**：用于重访后的全局优化，但不是核心因果前向注意力的一部分。

## 5. 方法一：Geometric Local Attention

### 5.1 为什么长期状态之前仍需要局部注意力

固定状态只负责保存被写进去的信息，不能自动把错误匹配变正确。相邻帧中的局部几何对应仍需要高分辨率、细粒度处理。

例如两面外观相似的墙：

- 只看纹理时，它们可能产生错误对应；
- 加入时间、高度和宽度位置后，模型更容易判断它们来自不同帧、不同区域；
- 若某个注意力头仍给出混乱匹配，可靠性门控会压低它。

### 5.2 Head-wise reliability gate

教程采用论文门控思想表示为：

\[
g_h=\sigma(W_g\bar{x}+b_g),\qquad \tilde{y}_h=g_hy_h
\]

- \(h\)：注意力头索引。
- \(\bar{x}\)：局部窗口特征的池化表示。
- \(g_h\in(0,1)\)：第 \(h\) 个头的可靠性。
- \(y_h\) 与 \(\tilde y_h\)：门控前后该头的输出。

当某个头负责的对应一致时，\(g_h\) 较高；当它被动态物体、反光、重复纹理或遮挡干扰时，输出被压低。其作用是减少噪声进入后续持久状态，也缓解局部注意力中的异常集中。

### 5.3 Spatiotemporal RoPE

图像 patch 的位置由三轴坐标表示：

\[
\pi=(t+1,y+1,x+1)
\]

它同时表达时间、高度和宽度，使相同纹理在不同帧、不同图像区域中仍可区分。MRT 与位姿 Token 使用特殊原点 \((0,0,0)\)，从普通图像 patch 的坐标约定中分离出来。

### 5.4 这一模块的边界

- 它解决的是局部对应可靠性，不承担无限历史存储。
- 动态前景仍可能制造一致但错误的“运动几何”，因此门控并非万能动态场景分割器。
- 教程动画里的门值是机制示意，不是论文模型实际导出的头权重。

## 6. 方法二：Geometric Linear Attention

### 6.1 固定状态怎样持续更新

核心递归可写为：

\[
S_t=\operatorname{diag}(\gamma_t)S_{t-1}+\phi(k_t)\tilde v_t^{\top}
\]

\[
o_t=q_t^{\top}S_t
\]

- \(S_t\)：时刻 \(t\) 的固定大小几何状态。
- \(\gamma_t\)：逐通道保留率向量。
- \(\operatorname{diag}(\gamma_t)S_{t-1}\)：先按通道衰减旧状态。
- \(\phi(k_t)\tilde v_t^{\top}\)：把当前键和值形成的低秩几何证据写入状态。
- \(q_t\)：当前查询。
- \(o_t\)：从持久状态读取的长期几何输出。

状态外形不变，但内容每帧都在衰减、写入和读取。因此 \(O(1)\) 指持久状态大小相对序列长度为常数，不代表显存为零，也不代表每帧没有计算。

### 6.2 逐通道保留率为何是关键

通道 \(c\) 的有效记忆寿命可理解为：

\[
\tau^{(c)}=-\frac{1}{\log \bar\gamma^{(c)}}
\]

\(\bar\gamma^{(c)}\) 越接近 1，寿命越长。不同通道于是可以分工：

- 低保留通道：快速更新局部纹理和短期对应；
- 中保留通道：保存运动与跨帧结构；
- 高保留通道：保存更持久的场景布局和尺度线索。

数学示例，不是论文学习到的真实参数：

- \(\gamma=0.9\) 时，100 步后剩余约 \(0.9^{100}\approx2.7\times10^{-5}\)；
- \(\gamma=0.99\) 时，100 步后仍有约 \(0.366\)；
- \(\gamma=0.999\) 时，100 步后仍有约 \(0.905\)。

同一个固定矩阵因此能同时承载短、中、长三种时间尺度，而不是把所有证据平均地记同样久。

### 6.3 为什么陈旧初始化会消失

若保留率存在统一上界 \(\bar\gamma<1\)，初始化状态的影响满足：

\[
\left\|q_t^{\top}
\left(\prod_{j=1}^{t}\gamma_j\right)S_0\right\|
\le
\|q_t\|\,\|S_0\|_F\,\bar\gamma^t
\rightarrow0
\]

这说明陈旧初始化会指数衰减。结论带有明确前提：

- \(\bar\gamma<1\)：旧影响趋于消失；
- \(\bar\gamma=1\)：不保证衰减；
- \(\bar\gamma>1\)：已经违反论文推导前提，不能套用有界结论。

### 6.4 为什么称为线性注意力

历史键和值被压入固定状态，而不是让当前查询与所有历史 Token 重新做完整两两注意力。因此随序列推进：

- 每帧更新时间近似固定；
- 总时间随帧数近似线性增长；
- 持久状态大小不随帧数增长。

这正是从 48 帧训练推广到万帧评测所需的结构前提，但结构可扩展不等于任意数据上都没有误差。

## 7. 方法三：Metric Readout Tokens 与位姿融合

### 7.1 为什么尺度必须单独读出

单目几何中，深度和平移天然存在尺度耦合。若深度使用一把尺、平移使用另一把尺，二者无法组成同一个三维世界。

MRT 从高保留的持久几何中读取尺度：

\[
\hat s=\exp(g(z_{\text{metric}}))
\]

然后同一个正尺度同时作用于平移和深度：

\[
\hat t=\hat s\,\hat t_{\text{raw}},\qquad
\hat D=\hat s\,\hat D_{\text{raw}}
\]

- \(z_{\text{metric}}\)：MRT 表示。
- \(\hat s\)：预测尺度；指数映射保证它为正。
- \(\hat t_{\text{raw}}\)、\(\hat D_{\text{raw}}\)：校准前的平移与深度。

通俗理解：不是额外预测一个孤立数字，而是从长期保存的几何基准中取出同一张标定卡，同时校准“相机走了多远”和“物体离相机多深”。

### 7.2 多位姿 Token 融合

只沿关键帧顺序链传播位姿时，每一段误差都会传给下一段。论文使用局部窗口中的多个位姿 Token 共同读出相对位姿，相当于让多个局部证据共同投票，降低对单一路径链式累积的依赖。

联合训练目标可概括为：

\[
\mathcal L=
\lambda_{\text{pose}}\mathcal L_{\text{pose}}
+\lambda_{\text{depth}}\mathcal L_{\text{depth}}
+\lambda_{\text{scale}}\mathcal L_{\text{scale}}
\]

尺度监督只在具有度量标注的样本上成立，不能暗示所有训练数据都具有相同尺度真值。

## 8. 训练与推理事实

- 论文使用 48 帧训练片段。
- 实现中以 21 帧 chunk 处理，位姿预测局部窗口 \(W=10\)。
- 论文报告模型能够推广到超过 10000 帧的测试序列。
- 论文报告持久状态大小近似恒定，总运行时间随序列长度近似线性。

这组事实最有价值的地方是“短训练、长推理”，但正确表述应是：

> 论文实验表明该递归结构在报告的数据和协议下具有明显的长度外推能力。

不要说“训练 48 帧已经数学保证任意 10000 帧永不漂移”。

## 9. 实验应当怎样读

### 9.1 三类证据不能混为一谈

1. 官方视频：展示轨迹和重建的定性行为。
2. ATE 表格：量化相机轨迹误差，越低越好。
3. 资源曲线：说明状态和运行开销是否随帧数失控。

视频看起来稳定不能替代 ATE；ATE 较低也不能单独证明资源恒定。

### 9.2 Table 6：vKITTI2 消融

| 变体 | 80 帧 ATE | 200 帧 ATE | 1000 帧 ATE |
|---|---:|---:|---:|
| Full model | **0.42** | **0.71** | **1.20** |
| w/o Geometric Linear Attention | 0.83 | 2.06 | 5.38 |
| w/o channel-wise gating | 0.67 | 1.43 | 3.21 |
| replace with TTT-like fixed weight | 0.58 | 1.56 | 3.96 |
| w/o Geometric Local Attention | 0.78 | 2.64 | 7.46 |
| w/o head-wise output gating | 0.61 | 1.74 | 4.06 |
| w/o Geometric RoPE, 2D spatial only | 0.64 | 1.22 | 2.58 |

| single-token pose, no aggregation | 0.51 | 1.10 | 2.67 |

最重要的不是背完表格，而是固定 1000 帧这一列读因果链：

\[
1.20\;\text{Full}
<
3.34\;\text{w/o MRT}
<
5.38\;\text{w/o Linear}
<
7.46\;\text{w/o Local}
\]

解释：

- 去掉 Local 后误差从 1.20 升到 7.46，说明长期状态之前的精确局部对应非常关键。
- 去掉 Linear 后升到 5.38，说明只靠局部窗口无法维持长时几何。
- 去掉 MRT 后升到 3.34，说明稳定尺度读出对长序列不可忽略。
- 单 Token 位姿为 2.67，支持多 Token 融合。
- 这些差异在 80 帧时较小，到 1000 帧显著放大，正好对应论文研究的长时问题。

## 10. 论文真正证明了什么，又没有证明什么

论文支持：

- 局部可靠性、逐通道长时保留和度量读出都对长序列有效；
- 固定大小递归状态能够避免历史 Token 线性堆积；
- 短训练片段可以在报告设置中外推到很长测试序列；
- 可选回环闭合能进一步改善部分重访轨迹。

论文没有证明：

- 任意场景、任意长度都零漂移；
- 固定状态能够无损保存所有历史细节；
- 动态物体、重复纹理和强视觉歧义已经被彻底解决；
- 带 LC 的最好结果全部来自核心前向注意力。

## 11. 局限性

### 11.1 固定状态的容量瓶颈

状态大小不增长意味着历史被压缩。它可能记住城市轮廓和尺度，却忘掉精确重访所需的一扇相似门、一个小路口或局部纹理。

### 11.2 重复访问与视觉歧义

相似走廊、道路或建筑容易产生错误重定位。多时间尺度保留改善长期稳定，但不等价于显式地点检索。

### 11.3 动态前景污染

车辆、行人等动态物体可能形成强局部对应并写入状态。逐头门控能抑制部分不可靠头，但不是完整的动态静态分解方案。

### 11.4 Loop Closure 是独立可选模块

LC 能改善重访一致性，却不是核心注意力机制天然提供的保证。报告结果时必须标注是否启用。

### 11.5 长度外推仍依赖训练分布

48 帧训练到万帧推理说明结构具备外推能力，不代表跨相机、跨运动模式、跨动态程度都同样稳健。

## 12. 可以继续探索的方向

以下均是基于局限的合理推断，不是本文已经完成的贡献：

1. **固定状态 + 稀疏外部检索记忆**：常规帧走固定状态，检测到重访时检索少量关键帧或地点描述子。
2. **自适应保留率与容量分配**：根据场景新颖度、运动速度或不确定性动态决定哪些通道应延长寿命。
3. **动态静态分解后再写状态**：显式识别动态前景，避免把车辆或行人的运动当作静态场景几何。
4. **带不确定性的写入门控**：不仅输出深度置信度，也让不确定性直接控制长期状态写入强度。
5. **可微回环与前向状态联合训练**：减少核心模型与后处理 LC 之间的割裂，但需要控制计算与因果边界。
6. **跨传感器尺度校准**：利用 IMU、轮速或稀疏深度增强 MRT 的尺度稳定性。
7. **系统研究短训长测规律**：分析训练长度、场景覆盖和保留谱之间的关系，而不只报告单个 48→10K 结果。

## 13. 四分钟汇报路线

页面中的官方视频、Figure 1、Figure 3、GLA 状态更新、局部门控、MRT、消融和结尾卡均默认自动演示；鼠标手动选择任一状态后会暂停自动轮播。现场只需要用顶部导航完成四次定位，不需要追着控件连续点击。

> 状态更新是 \(S_t=\mathrm{diag}(\gamma_t)S_{t-1}+\phi(k_t)\tilde v_t^T\)。外框不增长，但内容持续更新，所以持久内存相对序列长度是常数。

## 14. 评委可能追问

**Q1：为什么有 Linear Attention 还需要 Local Attention？**

Linear 状态负责跨窗口保留，不能替代精细局部对应。若错误匹配先写入长期状态，后面只会长期保存错误。1000 帧消融中去掉 Local 的 ATE 从 1.20 升到 7.46。

**Q2：固定状态是不是一定会忘掉重要信息？**

会有容量边界。论文通过逐通道保留率学习“忘什么、忘多快”，减少无差别遗忘，但不能无损保存所有历史细节。

**Q3：48 帧训练为什么能跑到 10000 帧？**

因为递归更新规则与序列总长度无关，测试时可以重复应用同一更新；逐通道衰减还控制陈旧影响。但这是结构解释和实验观察，不是任意数据上的绝对保证。

**Q4：MRT 与普通回归一个尺度有什么区别？**

MRT 从持久几何状态读取尺度，并用同一个正尺度同时校准平移与深度，使两者保持在同一三维坐标尺度中。

**Q5：Loop Closure 是论文核心模块吗？**

不是。它是可选的独立增强。核心因果前向模型是 Local Attention、Linear Attention、MRT 与位姿/深度预测。

**Q6：为什么 gamma 不能直接等于 1？**

若所有相关保留率长期为 1，陈旧初始化和噪声不再保证衰减；论文的有界推导依赖统一上界 \(\bar\gamma<1\)。

**Q7：论文最大的实验说服力是什么？**

不是单纯“能跑万帧”，而是随着 80→200→1000 帧增长，各关键部件的消融差距明显扩大，同时持久状态大小不随序列长度增长。

**Q8：你认为最值得改进的点是什么？**

在固定状态之外加入受控的稀疏重访检索：常规帧保持常数状态，只有检测到地点重访或高不确定性时才访问少量关键帧。

## 15. 临场只背这六句

1. 能处理一万帧，不等于一万帧后仍稳定。
2. 旧方法的问题不是记得少，而是不同几何被迫用同一种忘法。
3. \(K=K_{spatial}K_{time}\)：先判断信不信，再决定记多久。
4. Local 筛可靠对应，Linear 用逐通道 gamma 保留多种寿命，MRT 统一尺度与位姿。
5. 1000 帧 ATE：Full 1.20，w/o MRT 3.34，w/o Linear 5.38，w/o Local 7.46。
6. 不是记住一切，而是让不同几何证据用不同速度遗忘。
